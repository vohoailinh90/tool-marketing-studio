Handed work to AI agents and then wondered who's actually working, who's waiting, and how much of the budget is gone? 👇

I built a small "agent office" page so one look answers it. The main session sits on top, departments below, one desk per agent, and a line joins two cards while work is handed over. The page only reads.

Each card shows a state (Idle, Waiting, Working, Reviewing, Done, Blocked), progress, and budget: the base and each reserve are shown separately, and a reserve not yet granted is dashed. There's a timestamped handoff log and a time slider to replay a whole run at 1×, 2×, 4× or 8×.

My favourite part is that the page says where it doesn't know. Per-agent progress is an estimate (marked ~, capped at 95% until the agent reports done). The main session's phase is inferred. Silent for 15 minutes, or asked to start and still not running after 2, shows as Blocked. No budget recorded? It says so.

The numbers come from an observer hook that only records and never blocks a tool. It doesn't store prompts, full replies, tool inputs or transcript paths. The page binds to 127.0.0.1 by default and has no login, so on a VPS use an SSH tunnel.

The images are a recorded sample run, not a real requirement. Limits: the repo is private; the hook was checked on one Claude Code build and one agent type; assigning or cancelling work from the page would be a different requirement.
