Đọc và review thay đổi của agent (diff)

• File nào đổi?: Có đúng file bạn nghĩ không
• To hay nhỏ?: Việc nhỏ mà diff to là lạ
• Đọc phần bạn hiểu: Chữ, số, tên hiển thị
• Tìm dấu hiệu lạ: Dòng bị xóa, file mới, mật khẩu
• Giữ, hỏi hay từ chối: Và nói rõ vì sao
