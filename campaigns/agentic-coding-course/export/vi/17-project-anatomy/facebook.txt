Nút bấm chạy qua những phần nào?

Giải phẫu một dự án: frontend, backend, database, API

• Frontend: Người dùng nhìn và tương tác
• Backend: Xử lý yêu cầu và quy tắc
• Database: Giữ dữ liệu để dùng lại
• API như thực đơn: Cách các phần yêu cầu nhau
• Giao đúng phạm vi: Chỉ đúng phần, kiểm tra diff

Biết vai trò và đường đi giúp bạn giao đúng phần cho agent.
