Bilingual invites without an API key: Copilot does the translating, you do the pasting 🌏

Pick English, Japanese, Vietnamese, or bilingual Japanese + English. For the bilingual one, write your note in any language, copy it with the event details and a ready-made prompt, paste it into Microsoft Copilot, and paste the answer back. Each half of the e-mail gets its own greeting — Japanese first, English second.

You can preview and edit before sending, and wording you add to the fixed part is translated too.

Honest limit: the copy-paste is a manual step, not automatic translation.
